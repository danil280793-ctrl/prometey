Логика работы
• ст / ж-б / пэт — параметры товара. Нажатие переключает выбор.
• Клик по названию — включает/выключает ВСЕ параметры сразу.
• Москвич ст+ж-б — комбо выводится после блока ст.
• Бочкарев комбо — без дублей, строго по паттернам (ст 0,43/пэт 0,9 и т.д.).
• Жигулевское / Охота — ж-б+пэт образуют комбо ж-б 0,43/пэт 1,2.
